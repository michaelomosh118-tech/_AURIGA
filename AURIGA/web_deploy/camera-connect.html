SERIAL / MICROCONTROLLER BRIDGE

Uses the Web Serial API (Chrome 89+, Edge 89+) to connect directly to any microcontroller with a USB-serial adapter — PIC, AVR, STM32, ESP32, RP2040, Arduino, and more. The MCU sends JPEG frames over UART; Auriga renders them in real time.

PIC MICROCONTROLLER FIRMWARE REFERENCE

For PIC18F or PIC32 connected to an OV7670 / OV2640 camera module. Tested on PIC18F4550 (USB) and PIC32MX (UART + USB-serial adapter).

// PIC18F4550 — OV7670 capture → USB-CDC JPEG stream // Camera module: OV7670 (QVGA 320×240) // Compiler: XC8 v2.x, MCC generated USB CDC #include "mcc_generated_files/usb/usb_device_cdc.h" #include "ov7670.h" // your OV7670 SCCB driver void main(void) { OV7670_init(QVGA, JPEG, Q10); // 320×240 JPEG quality 10 while(1) { uint8_t *buf; uint32_t len; OV7670_capture(&buf, &len); // capture one JPEG frame // Send with JPEG SOF/EOF — Auriga auto-detects 0xFF 0xD8 … 0xFF 0xD9 CDCTxBuffer(buf, len); CDCFlushTxBuffer(); // ~15 fps at 115200 baud with QVGA JPEG } } // For PIC32: use UART2 at 921600 baud for higher frame rates // uart_write(buf, len) → USB-UART adapter → Chrome Web Serial API
// STM32F4 — DCMI + DMA → USB CDC JPEG stream #include "stm32f4xx_hal.h" extern DCMI_HandleTypeDef hdcmi; void stream_frames(void) { while(1) { HAL_DCMI_Start_DMA(&hdcmi, DCMI_MODE_SNAPSHOT, frame_buf, BUF_LEN); HAL_Delay(33); // ~30 fps // JPEG is in frame_buf — send via USB CDC or UART CDC_Transmit_FS(frame_buf, jpeg_len); } }

BLUETOOTH CAMERA

Uses the Web Bluetooth API to connect to BT LE camera modules — including ESP32-based Bluetooth cameras, Nordic Semiconductor nRF52-based systems, and custom BT camera accessories. Receives JPEG frame chunks over BLE notify characteristics.

ESP32 BLE CAMERA FIRMWARE REFERENCE

// ESP32 — OV2640 camera → BLE GATT JPEG frame streamer // Chunk size: 512 bytes per BLE notify (MTU negotiated to 517) #include "BLEDevice.h" #include "esp_camera.h" #define SERVICE_UUID "12345678-1234-5678-1234-56789abcdef0" #define CHAR_UUID "12345678-1234-5678-1234-56789abcdef1" BLECharacteristic *pChar; void streamFrame(camera_fb_t *fb) { uint32_t total = fb->len; // Send length header first (4 bytes little-endian) uint8_t hdr[4] = {total&0xFF,(total>>8)&0xFF,(total>>16)&0xFF,(total>>24)&0xFF}; pChar->setValue(hdr, 4); pChar->notify(); // Send JPEG in 512-byte chunks for(uint32_t i=0; i<total; i+=512) { uint32_t chunkLen = min(512U, total-i); pChar->setValue(fb->buf+i, chunkLen); pChar->notify(); delay(5); // BLE congestion control } } void loop() { camera_fb_t *fb = esp_camera_fb_get(); if(fb) { streamFrame(fb); esp_camera_fb_return(fb); } delay(66); // ~15 fps }
// nRF52840 (Nordic) — BLE camera module firmware sketch // OV7670 attached via parallel data bus + PCLK/HREF/VSYNC // Transmits JPEG chunks identical to ESP32 above // Use same SERVICE_UUID / CHAR_UUID in Auriga Camera Connect
