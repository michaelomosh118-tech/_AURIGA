Capabilities

Nine engines. One phone.

Always on.
01 Object Locator 80 COCO classes detected with live bearing and distance. Spoken on acquisition at ~3 fps. YOLOv8n TFLite · NV21 pipeline
02 Crossing Guard™ Traffic light state fused with vehicle approach detection. Safe-to-cross confirmation only when both conditions clear. Dual-engine fusion · 3.5 s cadence
03 DrakoVoice™ Reader Point-and-read OCR for product labels, menus, expiry dates, and documents. AUTO mode, paragraph navigation. ML Kit Latin OCR · ZXing barcodes
04 Face Vault Enrol anyone. Recognised on sight from a 128-dimension local embedding. No photos stored. Works entirely offline. MobileFaceNet · cosine similarity
05 Passive Hazard Always-on audio classification. Smoke alarm, car horn, breaking glass, dog bark. Fires before your conscious reaction. YAMNet TFLite · 521 audio classes
06 Spatial Memory Walk a route once. Auriga stores the landmark sequence. Guided step-by-step replay on every return visit. 500 routes maximum. Topological map · token-overlap matching
Architecture

No server.
No subscription.
No compromise.

Every inference runs on TensorFlow Lite and Android ML Kit inside the phone's own hardware. Zero bytes leave the device. No API calls, no background uploads, no account required. Works in tunnels, in airplane mode, in a blackout, in countries with no data plan.
